# Product Listing Page

A multi-page storefront for an e-commerce brand, with home, skills and about pages behind a simple
sign-up / sign-in flow. Sign-in state is kept in `localStorage`, and routes redirect to the sign-in
page until the user is signed in.

**Stack:** React 18 · React Router 6

**Demo:** [product-listing-page-virid.vercel.app](https://product-listing-page-virid.vercel.app/signin)

## Running locally

```bash
npm install
npm start   # http://localhost:3000
```
