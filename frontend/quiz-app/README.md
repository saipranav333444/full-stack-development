# Quiz App

A multiple-choice quiz on HTML, CSS and JavaScript fundamentals, built with plain HTML, CSS and
JavaScript as a front-end assignment. Choose an answer, submit it, move to the next question and
see your score at the end.

**Stack:** HTML · CSS · JavaScript (no build step)

**Demo video:** [Google Drive](https://drive.google.com/file/d/17WqFXD_DE9fy8wh5mZX69iAIafrQ_DcT/view?usp=sharing)

## Running locally

Open `index.html` in a browser.
