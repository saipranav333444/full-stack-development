# ACCA Landing Page

A responsive marketing landing page for an ACCA (Association of Chartered Certified Accountants)
course. It has sections on the course, why to choose it, eligibility, placement assistance and
getting started, plus a modal form for requesting a call back.

**Stack:** React 18 · React Bootstrap · Bootstrap 5

## Running locally

```bash
npm install
npm start   # http://localhost:3000
```
